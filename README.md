# Employee Salary Prediction with Feature Scaling

This project demonstrates the importance of feature scaling in machine learning.

## Concepts Covered

- Normalization (Min-Max Scaling)
- Standardization (Z-Score Scaling)
- Data Visualization
- Linear Regression

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-Learn

## Project Structure

- data/ : Dataset
- images/ : Visualizations
- src/ : Python source code

## Learning Goal

Understand how feature scaling affects machine learning models and data preprocessing
